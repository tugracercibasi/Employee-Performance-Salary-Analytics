# Employee Performance & Salary Analytics Tool

A Python console application designed for tracking employee performance data, calculating salary adjustments, and generating department-based performance analytics with robust file I/O operations.

## Features

* **Employee Tracking:** Store and manage employee records efficiently using core data structures (Dictionaries, Lists, Tuples).
* **Salary Adjustments:** Automated calculations for performance-based salary increases.
* **Department Analytics:** Group and analyze performance metrics department-by-department.
* **File-Based Reporting:** Persistent data management using Python's file handling operations (`with` statements and `utf-8` encoding).

## Technologies Used

* **Python** (Core syntax, control structures, functions, file I/O)
* **Data Structures:** Dictionaries, Lists, Tuples
* **File Handling:** Context managers (`with`), text/data persistence
